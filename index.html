Secure, Efficient, and User-Friendly Health Data Management

Welcome to Your Health Management Solution

The Smart Health Record Management System (SHRMS) is a comprehensive desktop application built with Python and Flet, utilizing SQLite for robust data storage. It empowers healthcare professionals with role-based access (Admin, Doctor, Nurse) to manage patients, appointments, medical records, and billing securely. Features include user verification with ID uploads, activity logging, data backups/restores, and export/import capabilities for seamless workflows.

Patient & User Management

Register, update, search, and delete patients and staff with pending approval workflows and ID verification for secure onboarding.

Appointment Scheduling

Schedule, update, and manage appointments with conflict detection, buffer times, and role-specific views for doctors and admins.

Medical Records Handling

Add, edit, soft-delete, recover, and permanently remove records with detailed history, prescriptions, and lab results tracking.

Billing & Data Tools

Generate bills, track payments, perform full database backups/restores, and export/import patient data in JSON format.

Activity Logging & Dashboard

Monitor recent activities, view real-time stats (patients, appointments, bills), and get a comprehensive overview for efficient system administration.

User Profile & Security

Manage profiles with status indicators (Active/Deactivated), unique IDs, role changes, password updates, and enhanced verification for robust security.
